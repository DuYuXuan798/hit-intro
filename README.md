# HIT Intro

一个基于哈尔滨工业大学公开信息制作的静态简介页，目标是做成“更像高校官网首页”的一校三区总览页面。

## 项目思路

这个页面不是单纯的海报式展示，而是参考真实高校官网的新闻与服务门户结构：

- 视觉上使用蓝白为主、金色点缀的官方感配色
- 结构上使用双层导航、新闻主视觉、专题校区与服务大厅，减少大留白
- 内容上重点突出学校概览、一校三区、校园位置和高频入口
- 链接全部优先使用学校公开官方站点

页面目前由三部分组成：

1. `index.html`：页面结构和内容
2. `style.css`：整体视觉、响应式布局和组件样式
3. `script.js`：导航高亮、回到顶部、地址复制等轻交互

## 当前功能

- 双层导航与官方高频服务入口
- 工大要闻主视觉与新闻列表
- 哈尔滨、威海、深圳三地校区专题
- 官方招生、地图、图书馆和信息服务跳转
- 地址复制、移动端导航与减少动态偏好支持
- 回到顶部按钮与当前栏目导航提示
- 基础站点文件：`favicon`、`robots.txt`、`sitemap.xml`、`404.html`

## 本地运行

直接用浏览器打开 `index.html` 即可。

如果想通过本地服务器打开，也可以在项目目录下执行：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000`

## 后续完善方向

这个仓库后面可以逐步补成一个更完整的哈工大简介站点，建议按下面节奏推进：

1. 接入可审计的官方新闻数据源，替代静态新闻索引
2. 继续优化响应式和可访问性，比如键盘焦点样式与对比度检查
3. 增加 GitHub Pages 自动部署工作流
4. 进一步统一文案口径，尽量贴近学校官网的正式表达
