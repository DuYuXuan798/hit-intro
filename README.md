# HIT Intro

一个基于哈尔滨工业大学公开信息制作的静态简介页，目标是做成“更像高校官网首页”的一校三区总览页面。

## 项目思路

这个页面不是单纯的海报式展示，而是尽量往学校官网的门户风格靠：

- 视觉上使用蓝白为主、金色点缀的官方感配色
- 结构上把信息收拢成更紧凑的门户区块，减少大留白
- 内容上重点突出学校概览、一校三区、校园位置和高频入口
- 链接全部优先使用学校公开官方站点

页面目前由三部分组成：

1. `index.html`：页面结构和内容
2. `style.css`：整体视觉、响应式布局和组件样式
3. `script.js`：导航高亮、回到顶部、地址复制等轻交互

## 当前功能

- 首屏主视觉展示
- 学校概览与门户入口
- 一校三区与校区位置展示
- 高频官网入口
- 咨询信息与地址复制
- 移动端导航适配
- 回到顶部按钮

## 本地运行

直接用浏览器打开 `index.html` 即可。

如果想通过本地服务器打开，也可以在项目目录下执行：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000`

## 后续完善方向

这个仓库后面可以逐步补成一个更完整的哈工大简介站点，建议按下面节奏推进：

1. 补 `README` 之外的项目基础文件，比如 `favicon`、`robots.txt`、`sitemap.xml`
2. 加一个真正的新闻/通知模块，替代目前的快捷入口展示
3. 继续优化响应式和可访问性，比如键盘可操作、焦点样式、对比度
4. 增加 GitHub Pages 部署说明，让页面可以直接在线访问
5. 进一步统一文案口径，尽量贴近学校官网的正式表达

## 说明

本项目是基于公开信息整理的展示页，不代表哈尔滨工业大学官方网站。
