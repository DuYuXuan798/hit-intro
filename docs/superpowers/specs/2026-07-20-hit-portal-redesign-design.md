# 哈工大简介站门户化视觉重构设计

## 目标

将现有的单页简介站重构为更接近真实高校官网的紧凑门户首页：以新闻、快捷服务和三地校区为核心，同时通过更精致的蓝金视觉、动态与专题编排建立记忆点。

## 参考原则

- 以哈工大官网的“重要新闻 + 快速访问通道 + 专题栏目”作为信息骨架。
- 借鉴清华大学官网的双层导航：顶层服务入口面向不同人群，主导航组织学校内容。
- 保留静态单页实现，不伪造官方身份；所有外部跳转继续指向官方域名。
- 视觉应比常规高校门户更有仪式感，但不能牺牲导航、文字对比度和移动端可读性。

## 信息架构

1. 顶部服务栏：校园门户、新闻、图书馆、邮箱、地图、英文站等高频官方入口。
2. 主导航：学校概览、工大要闻、一校三区、服务大厅、联系信息。
3. 主视觉：一张官方公开校园/新闻图片，叠加简短校名、时间线信息与主操作按钮。
4. 首屏新闻区：主新闻卡与精简新闻列表，新闻标题可直达官方新闻站。
5. 一校三区专题：横向三站式编排，提供校区定位、地址、官网和地图入口。
6. 服务大厅：招生、地图、图书馆、邮箱、信息公开、国际教育等轻量功能入口。
7. 页脚：三地地址、信息来源、版权说明和返回顶部。

## 视觉系统

- 基调：深海军蓝、明亮电光蓝、暖金色、冰白色。大面积深色用于首屏和专题区，白色用于信息密度较高的门户内容。
- 字体：中文使用具有书卷气的衬线字体；英文字母采用高字距无衬线作为信息标签，避免默认 UI 字体的模板感。
- 材质：在首屏和专题区使用低透明度的蓝图网格、细金边和柔和光晕；正文卡片保持实体白底与清晰分隔。
- 版式：以 12 栏容器为基准。桌面端新闻采用 7:5 编排，三地校区采用连续横向轨道；小屏改为单列。
- 动效：只使用渐进显现、标题光带、悬停位移和计数微动效；尊重 `prefers-reduced-motion`。

## 交互与降级

- 所有外部链接使用新窗口打开并保留 `rel="noreferrer"`。
- 地址复制优先使用 Clipboard API；不可用时提示用户手动复制。
- 图像载入失败时显示深蓝渐变背景和可读标题，不出现失控的大块空白。
- 小屏菜单可展开和关闭；每个主要链接的点击目标不小于 44px。

## 验收标准

- 页面首屏可在 1 屏内识别学校、访问官网、浏览核心新闻与快捷入口。
- 正文不再由单一白色大卡片构成，新闻、专题、服务区具有明确视觉节奏。
- 三地校区地址、官网与地图入口仍完整可用。
- 320px 至桌面宽度下内容无横向溢出，导航与链接可操作。
- 降低动态偏好开启时不执行滚动显现和连续动画。
